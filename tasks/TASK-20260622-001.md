## Search 成果物

### 要求定義(S1)

**何を作るか**: HyperHelix 更新時に Codex 補完用 `hyperhelix-commands` skill を最新化できる `node tools/hyperhelix.mjs update-codex-skill` を追加し、README に使用法を載せる。

**なぜ作るか**: 手動で `~/.codex/skills/hyperhelix-commands` を編集する運用だと、HyperHelix 側のコマンド仕様更新に追従しない。repo 側から薄い skill を再生成し、詳細は live repo (`--help` / AGENTS / CLAUDE / git-conventions) を権威にする。

**成功条件**:
1. `update-codex-skill --dry-run` が書き込み先を表示する。
2. `update-codex-skill` が `~/.codex/skills/hyperhelix-commands/SKILL.md` と `agents/openai.yaml` を再生成する。
3. 生成された skill が `quick_validate.py` で valid。
4. `node tools/hyperhelix.mjs --help` に新コマンドが表示される。
5. `node tools/hyperhelix.mjs validate` が error 0。

**スコープ外**: Codex アプリ側の補完キャッシュ即時リロード(新規スレッド/再起動が必要な場合あり)。

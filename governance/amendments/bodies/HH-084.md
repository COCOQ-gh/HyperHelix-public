# HH-084 — S2(知見の検索)の実行を standard/full の記録の必須証跡にする — `notes.retrieved` が空なら、引いたタグと「該当なし」を `phase_evidence.search` に書かなければ finish / verify が止める

**Status:** Approved(2026-10-26 ユーザー承認 — 「HH-084 を承認する」の直接指示。裁可事項 1〜4 とも)
**ratified_by:** COCOQ-gh
**ratified_at:** 2026-10-26
**種別:** ループ定義変更(standard/full の S2 証跡の必須化・finish / verify の fail-closed 範囲の拡大)。HH-083(D3/D4 の振り分け)と同じ形を Search 側に適用する

## 背景

`core/loop.yaml` の standard / full は `required_steps` に S2(タグ検索で既存の知見を引く)を含むが、
`finish` / `verify` は hh-record の `notes.retrieved` が空でも通す。空の意味が「引いたが該当なし」か「引いていない」か
記録から区別できず、必須ステップの欠落が黙って通る。あるホストプロジェクトの作業記録では、standard / full の記録の
少なくない割合で `notes.retrieved` が空だった。

実害もあった。あるタスクが、繰り返し行う処理の知見を playbook ノートとホスト側の手順書にまとめた。
その直後に、圧縮をはさんで再開した別の長命セッションが S2 を引かず、自分の古い方法で同じ処理を続けた。
直したばかりの問題の 2 回目である。該当のタグで `notes --tags` を 1 回引いていれば、追加されたばかりの playbook が先頭に出ていた。

同じ構造の穴を HH-083 が Distill 側(D3/D4 の振り分け)で塞いだ。Search 側は未対応で、知見が「入る」経路を直しても
「引く」経路が省略されれば届かない。チェックリスト(search.md S2)に手順はあるが、配送の無い注意は読まれない(既存ノートの実測、
HH-083 の却下案 (b) と同じ)。

## 裁可事項(案)

1. **S2 の証跡を standard / full の記録で必須にする**: hh-record の `notes.retrieved` が空(`[]`)のとき、`phase_evidence.search` に
   S2 の実行行 — 引いたタグと結果 — を 1 行以上含むことを `finish` / `verify` の検査に加える(fail-closed)。
   形は `S2 notes --tags <a,b,…> → 0 件(該当なし)` のように、`S2` と `--tags` を含む行(機械検査はこの 2 語の有無)。
   `notes.retrieved` が 1 件以上あれば従来どおり S2 の証跡とみなす。
2. **light / micro は対象外**(軽さを保つ)。ただし `finish` は light で `retrieved` が空かつ S2 行が無い記録の件数を表示する(表示のみ、HH-083 の 3 と同じ形)。
3. **移行**: `verify --base` は cutover 日(実装時に `commit-record.mjs` の定数で指定)より前の commit を免除する(HH-083 の `DISTILL_ROUTING_CUTOVER` と同じ)。
4. **S2 の結果を書く場所は 1 つ**: `phase_evidence.search` の行。`notes.retrieved` は従来どおり引けた id の一覧とし、
   「該当なし」を id の代わりに書かない(id の実在検査と衝突する)。

## 却下した代替案

- **(a) search.md S2 のチェック行を強める** — 手順は既に明記されている(`do NOT grep the full ledger` まで書いてある)のに繰り返し飛ばされた。配送の無い注意は読まれない。
- **(b) `notes.retrieved` を非空必須にする** — 本当に該当が無い作業(新しい領域の最初のタスク)で、無関係なノートを書いて通す誘因になる。「引いて該当なし」は正当な結果として残す。
- **(c) `brief` が S2 を自動実行する** — `brief` はタスクの主題の語彙を知らない(タグは S1 の結果)。起動時の 1 回だけでは、既存ノートの観測(主題の語彙だけで組むと操作の知見が落ちる)を再現する。補助としては `brief` の出力に「S2 を引いたら記録せよ」の 1 行を足してよいが、強制は記録の検査で行う。
